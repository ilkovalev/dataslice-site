# Канон терминов курса

Единый источник правды для всех текстовых поверхностей: глоссарий,
`tooltipTerms.js`, `definitions[]` внутри уроков, проза уроков.

Проверяется автоматически: `node scripts/check-terms.mjs` (входит в `npm run build`).

## Почему это нужно

Определения живут на четырёх поверхностях, и они уже расходились: глоссарий
говорил «асимметрия», уроки в 28 местах — «скошенность»; глоссарий —
«ложноположительный результат», тултипы — «ложное срабатывание». Читатель
видит оба варианта и не понимает, один это термин или два разных.

## Статистика

| Норма | Не писать | Почему |
|---|---|---|
| асимметрия (распределения) | скошенность, скос | принято в русской статистике; «скошенность» — калька со skew |
| ложноположительный результат | ложная тревога, ложное срабатывание | формулировка русскоязычных источников |
| ложноотрицательный результат | пропуск эффекта | то же |
| ошибка первого / второго рода | ошибка I / II рода | словом, а не римской цифрой |
| мощность критерия | — | |
| стандартная ошибка | — | не путать со стандартным отклонением |
| выборочное распределение | распределение выборки | это распределение статистики, а не данных |

## Машинное обучение

| Норма | Не писать | Почему |
|---|---|---|
| признак | фича | «фича» допустима один раз в скобках при первом введении термина |
| точность (precision) | — | русское слово первым, английское в скобках |
| полнота (recall) | — | то же |
| отложенная выборка | холдаут | |

## Бизнес-метрики

| Норма | Не писать | Почему |
|---|---|---|
| маржинальная прибыль | маржа вклада | принято в русском управленческом учёте |
| средний чек | средний receipt | |
| отток | чёрн | |

Заимствования, которые остаются как есть, потому что так говорит отрасль:
take rate, юнит-экономика, апсейл, кросс-сейл, когорта, бутстреп, guardrail.

## Обращение к читателю

- Только **«вы»**, со строчной буквы. Никакого «ты» и его глагольных форм.
- Прописная «Вы» — тоже ошибка: в курсе принята строчная (было 38 против 5,
  расхождение устранено).

## Связность

- Не отсылать к понятию, которого в уроке не вводили. «Эта рамка меняет…»
  при отсутствии слова «рамка» выше по тексту — дефект.
- «Поэтому», «отсюда», «это» должны иметь понятный антецедент в пределах
  видимого читателю текста.

## Регистр

Учебный текст, а не разговор. Не писать: «кучные», «гуляет», «невезучие»,
«затевается», «буксует», «в проде», «разваливается», «накрутить»
(в значении «подтасовать» — допустимо только про закон Гудхарта, где это термин).
